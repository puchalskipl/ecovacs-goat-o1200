# Ecovacs GOAT

Mower-only Home Assistant custom integration for ECOVACS GOAT lawn mowers,
tuned for the **GOAT O1200 LiDAR Pro** (O-series); the GOAT G1 line is also
supported. The integration domain is `ecovacs_goat`.

See the repository root `README.md` for installation, setup, the dashboard
card, the live-map architecture, troubleshooting, and safety notes, and
`docs/protocol-summary.md` for sanitized protocol details (map geometry
decoding included).
